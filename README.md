## 파일 설명

| 파일 | 설명 |
|------|------|
| hello.c | Hello, world 출력 |
| sum.c | 1부터 10까지의 합 계산 |
| max.c | 배열에서 최댓값 찾기 |
| gugudan.c | 2~9단 구구단 출력 |
| factorial.c | 재귀로 1!~10! 계산 |
| fibonacci.c | 피보나치 수열 15개 출력 |
| reverse.c | 문자열 뒤집기 |
| prime.c | 1~50 사이 소수 출력 |
| bubble_sort.c | 버블 정렬 |
| swap.c | 포인터를 이용한 두 값 교환 |
